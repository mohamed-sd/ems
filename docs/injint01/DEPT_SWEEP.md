# ② الجوابُ على الأسئلةِ الأربعة

## ① الستّةُ والأربعون — لا «اثنان وثلاثون باقية»

الجردُ **كاملٌ ومغلق**:

```
46  =  43 معروضٌ بلا خطأ  +  3 يردُّها الحارس
```

**والرقمُ 32 من عمودٍ آخر:** جدولُ العُدّةِ يقول `حذف · غيرُ موجود = 32` — أي **32 سطحًا لا يُعلِن مانيفستُهم عمليّةَ حذف**، لا 32 سطحًا مجهولَ الحال.

## ② الخمسةَ عشرَ — **ليست سلّةً جاهزة**

سألتَ: أهي في الدليلِ المعماريِّ أصلًا؟ **قِستُها بالسجلِّ الحاكم `nav_targets`:**

```
هدفٌ في الدليلِ ينقصه رابط  =  0
خارجَ الدليلِ أصلًا         =  16
```

> ⇒ **لا واحدَ منها «مبنيٌّ ومسجَّلٌ وينقصه رابط».** كلُّها **تحتاج حكمًا لا رابطًا** — أَتدخل الدليلَ أم تُتقاعَد؟
> **فالسلّةُ تُضاف إلى عبءِ الفرزِ لا تُنقَص منه.** وهذا يعكس التقديرَ في رسالتك.
