# ⑥ أربعةُ نماذجَ بلا رمزِ CSRF 🟡

`user_capacities.php` — أربعةُ نماذجِ `method="post"` بلا حقلِ `csrf_token`:

```
:185  <form method="post" class="uc-inline">
:205  <form method="post"> … cap_action=derive_dry
:207  <form method="post"> … cap_action=derive_apply
:251  <form method="post" class="uc-freeze-form">
```

و`config.php` يحمّل عُدّةَ الرمز — **لكنَّ قاعدةَ مشروعِك المكتوبةَ تقول: الحقنُ الآليُّ يغطّي `fetch`/`XHR` لا النموذجَ العاديّ.**

فالنتيجةُ أحدُ أمرَين: تُردُّ 403 (وظيفةٌ مكسورة)، أو تمرُّ بلا حارسٍ (ثغرة). **ولم أُجرّبِ الإرسالَ — فهو كتابة.**
