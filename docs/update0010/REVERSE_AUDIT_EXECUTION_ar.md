## ② الاختلافات الثلاثة التي رصدتها المراجعة وكيف حُسمت

1. **«ems_restore_test غير موجودة» (إنذار كاذب):** فاحص المراجعة اتصل بحساب التطبيق الذي لا يملك امتيازًا على القاعدة المستعادة فلم يرها information_schema — الفحص بحساب root أثبت وجودها كاملة (48,525 صفًّا). **الدرس:** فحوص الوجود عبر information_schema تتأثر بامتيازات الفاحص.
2. **«27 شاشة مبذورة لا 28» (قصور نمط):** عدّ المراجعة الأول استخدم glob بمستوى واحد ففاتته شاشة؛ المسح التعاودي المستقل + إعادة تشغيل الباذر كلاهما أكد **28**.
3. **«توثيق تراجع الوحدات مبتور» (ملاحظة حقيقية صغيرة):** سطر التراجع الملحق بـowner_doc انبتر بطول العمود (بتر صامت — sql_mode متساهل). **التعطيل نفسه سليم وموثق هنا نصًّا:** التراجع = `UPDATE org_units SET active=1 WHERE unit_id IN (21,22,23)` — ولا أثر وظيفيًّا للبتر (صفر مراجع على الوحدات).
