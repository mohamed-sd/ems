## ٢ · «الرؤيةُ لا تساوي السلطة» (‏الأمرُ الأوّل · البند 27)

> **الرئيسُ التنفيذيُّ قد يرى الشركةَ كلَّها — ولا يعني ذلك أنّه يستطيع تنفيذَ
> كلِّ معاملةٍ بنفسِه. والنائبُ قد يرى الشركةَ كلَّها وسلطتُه يحكمها
> `Deputy Role + Authority Scope`.**

والقرارُ من مساحةِ القيادةِ **يمرُّ بمحرّكِ الاعتمادِ نفسِه** الذي يمرُّ به قرارُ
الإدارة — لا بمسارٍ موازٍ.

**ويُقاس:** صفرُ كتابةٍ من خدمةِ هذه الموجةِ في جدولِ نطاقٍ آخر.

## ٣ · «طلباتي» — القاعدةُ الرباعيّة (`DEC-OPEN-17` معتمَد)

```
Governance governs the registry
Domain owns request definition
AAM resolves approval authority
System executes routing
```

`Unified Request Type Registry` **قدرةٌ منصّيّةٌ مركزيّة**. والحوكمةُ تملك
**حوكمتَه** — قواعدَ الإنشاءِ والتسميةِ والملكيّةِ والصلاحياتِ والاستثناءِ
و`Versioning` و`Retirement` — **ولا تملك توجيهَ الطلباتِ اليوميّة**.
وكلُّ نطاقٍ يملك **تعريفَ طلبِه** هو. و`AAM` يحدّد **من يعتمد** ولا يحدّد
**إلى أين يذهب**.

⛔ **ومساحةُ عملي `Launcher + Projection` ولا تصير `Owner`** — نصُّ القرارِ حرفًا.
فـ«طلباتي» **يُطلِق** طلبًا يملك النطاقُ تعريفَه، **ويعرض** حالتَه، ولا يخزّن
حقيقتَه.

## ٤ · الصلاحيةُ سلسلةٌ لا رابطٌ ظاهر (‏البنود 20–35)

**الصلاحيةُ ليست: هل الرابطُ ظاهرٌ أم لا. ولا: دورٌ واحدٌ يفتح الصفحة.**

```
Identity → Company → Department → Project → Site → Record Scope
        → Field Scope → Action → State → Authority → Delegation
```

**وأربعةُ مستوياتٍ تُفصل ولا تُدمج:**

| المستوى | القاعدة |
|---|---|
| **الصفحة** | من يفتحها |
| **الحقل** | بعضُ الأدوارِ تفتح الشاشةَ **ولا ترى كلَّ حقولِها**: السعرُ · الراتبُ · الحسابُ البنكيُّ · هويّةُ المبلِّغِ · نتائجُ التحقيق |
| **الفعل** | من يعرض **ليس بالضرورةِ** من ينشئ أو يعتمد أو يرفض أو يعيد الفتحَ أو يصدّر — **ولكلِّ فعلٍ حارسٌ خادميّ** |
| **الحالة** | مسوَّدةٌ تُعدَّل · ومُقدَّمةٌ تتوقّف · **ومعتمَدةٌ لا `Overwrite` لها** بل تعديلٌ أو تصحيح |

⛔ **ولا `Admin Override` سرّيّ**: كلُّ تجاوزٍ مشروعٍ يمرُّ بـ
`Exception Request → Authority → Scope → Expiry → Reason → Audit`.
وبعضُ القواعدِ `NON_WAIVABLE`.

⛔ **ولا اسمَ شخصٍ صلبًا في شيفرة** — `Role + Scope` لا `Ahmed can approve`.
