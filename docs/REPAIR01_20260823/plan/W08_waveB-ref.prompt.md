### ٦-أ · رحلةُ الإثبات — شرطُ بوّابةٍ لا توصية

**رحلةُ العميل ورحلةُ المورد**

> **رحلةُ العميل:** فرصةٌ ← عرضُ سعر ← تفاوض ← عقد ← التزاماتُ العقد ← أمرُ عمل ← تنفيذٌ مقيس ← مستخلص ← فاتورة ← طلبُ اعترافٍ ماليّ ← تحصيل — والأثرُ يصل الماليّةَ عبر طلبِ اعترافٍ لا بكتابةِ قيد (§48).
   **رحلةُ المورد:** تأهيلٌ قانونيٌّ وائتمانيّ ← عقدُ توريد ← التزامٌ تعاقديّ ← استحقاق ← مطالبة ← تسويةٌ ← إقفال — والسالبُ يفتح ذمّةً مدينةً لا يُبتلَع.

**تُغلَّف الرحلةُ ببوّابةٍ داخل `repair01_w8_gate.php`** تشترط عبورَها **كاملةً** و**أثرًا تجاريًّا مقيسًا عند كلِّ مستهلك** — لا صفَّ حدثٍ مُنشَأً (§46).

⛔ **لا تُقبل المرحلةُ ببناءِ أسطحِها إن لم تعبر رحلتُها — ولو كانت كلُّ بوّاباتِها الأخرى خضراء.**

### ٦-ب · الفحصُ السلبيّ — شرطُ إغلاقٍ لا زينة
اكسرْ بندًا عمدًا ← أعِدْ تشغيلَ البوّابة ← يجب أن تسقط ← أرجِعْه.
لم تسقط؟ البوّابةُ عمياءُ والمرحلةُ **غيرُ مُغلقة** مهما كان الرقمُ أخضر.
ارسُ على أسماءِ الأصنافِ والمقاماتِ لا على العبارات — نصُّ حالةِ الخطأِ يطابق العبارةَ فيُخضِرُّ كذبًا.
اكتبْ `tools/repair01_w8_negative.php` على نمطِ `tools/repair01_w0_negative.php`.
