# RPR-W13 — عقودُ الأثرِ لأحداثِ الموارد البشرية والبلاغات

> ⛔ **مولَّدٌ من المخزن — لا تحرّره يدويًّا**: `php tools/repair01_w13_docs.php` يعيد كتابتَه.

⛔ **حدثٌ بلا عقدِ أثرٍ مسجَّلٍ لا يُنفَّذ** (§٧). و`W13-19` يقرأ **مفاتيحَ الأحداثِ من شيفرةِ الخدمةِ نفسِها** ويشترط لكلٍّ صفًّا هنا — فحدثٌ يُطلَق بلا عقدٍ يُسقط البوّابة.

◆ **والقبولُ يقيس الأثرَ التجاريَّ لا صفَّ الحدثِ المُنشَأ** (§46): عمودُ «أثرُ المستهلك» رقمٌ يتغيّر عند قارئٍ مسمًّى، ورحلةُ §٦-أ تقيسه محطّةً محطّة.
