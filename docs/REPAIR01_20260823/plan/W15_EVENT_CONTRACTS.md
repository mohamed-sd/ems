# RPR-W15 — عقودُ الأثرِ للأحداثِ الصادرةِ من المساحات

> ⛔ **مولَّدٌ من المخزن** — المصدر: `repair01_events` حيث `wave = 'W15'`.
> ⛔ **وحدثٌ بلا عقدِ أثرٍ مسجَّلٍ لا يُنفَّذ** — والقبولُ يقيس **الأثرَ التجاريَّ**
> لا صفَّ الحدثِ المُنشَأ، **وكلُّ مستهلكٍ بالاسم** لا «كلُّ المستهلكين».

**عقودٌ مسجَّلةٌ 4**

## `ws.request.launched` — إطلاق طلب من مساحة العمل عند مالكه

| البند | القيمة |
|---|---|
| المصدر | WS مساحة عملي · `Portal/my_requests.php` |
| المحفِّز | اختيار نوع طلب نافذ في السجل المركزي وضغط الإطلاق |
| الحمولةُ الدنيا | company_id · requester_user_id · type_code · owner_dept · owner_table · owner_row_id · authority_rule_id |
| مفتاحُ منعِ التكرار | `ws:req:{user_id}:{type_code}:{owner_row_id}` |
| الشروطُ المسبقة | نوع نافذ برابطة مالك مكتملة وخدمة مالك قائمة على القرص وحساب مربوط بموظف حيث يلزم |
| سياسةُ الإعادة | إعادة بلا أثر مضاعف بمفتاح منع التكرار |
| سلوكُ الفشل | رد خدمة المالك يوقف الإطلاق ولا يخلف صفا معلقا في مساحة العمل |
| التعويض | لا تعويض — لم يكتب شيء في مساحة العمل أصلا فلا شيء يعكس |

**المستهلكونَ بالاسمِ وأثرُ كلٍّ منهم:**

| المستهلك | الأثرُ المقيس |
|---|---|
| خدمة الإدارة المالكة (LeaveRequestService او MaintenanceCycleService او TicketRouter) | خدمة المالك تنشئ السجل بحالته الأولى عندها |
| إسقاط طلباتي | إسقاط طلباتي يعرض الصف من جدول مالكه بلا نسخة |
| محرك بنود العمل | محرك بنود العمل يفتح بندا للمستلم |

## `exec.decision.routed` — توجيه قرار قيادي إلى محرك الاعتماد

| البند | القيمة |
|---|---|
| المصدر | E1 مساحة الرئيس التنفيذي · `Portal/ceo_approvals.php` |
| المحفِّز | ضغط قرار في مساحة القيادة على مستند وارد من مالكه |
| الحمولةُ الدنيا | company_id · actor_user_id · action_key · doc_kind · doc_ref · state · prepared_by · amount |
| مفتاحُ منعِ التكرار | `exec:dec:{doc_kind}:{doc_ref}:{actor_id}` |
| الشروطُ المسبقة | قاعدة سلطة مسجلة للفعل ومن أعد لا يعتمد وحالة غير نافذة |
| سياسةُ الإعادة | إعادة القرار على مستند مقرر ترد بحالة نافذة لا بتكرار الأثر |
| سلوكُ الفشل | رد الحارس يمنع القرار ويقيد المنع في سجل المنع ولا يكتب في جدول المستند |
| التعويض | لا تعويض — لم يقع أثر عند رد الحارس |

**المستهلكونَ بالاسمِ وأثرُ كلٍّ منهم:**

| المستهلك | الأثرُ المقيس |
|---|---|
| ScopeEngine حلال السلطة | حلال السلطة يعيد رمز ردة أو مرجع قاعدة |
| سجل حدود السلطة | سجل الحدود يقرأ ولا يكتب |
| مصفوفة الاعتماد المالي | المصفوفة تعيد المستوى المطلوب |
| خدمة نطاق المستند | خدمة النطاق تنفذ القرار عند مالكه |
| أثر التدقيق | أثر التدقيق يقيد المحاولة بنتيجتها |

## `exec.project.opened` — فتح مشروع بقرار قيادي

| البند | القيمة |
|---|---|
| المصدر | E1 مساحة الرئيس التنفيذي · `Portal/project_charter.php` |
| المحفِّز | اعتماد فتح ميثاق مشروع بإفاداته كاملة وسلطة نافذة |
| الحمولةُ الدنيا | company_id · charter_id · project_name · client · sites_text · cost_center_code · actor_id · authority_ref |
| مفتاحُ منعِ التكرار | `exec:charter:{charter_id}` |
| الشروطُ المسبقة | الإفادات كاملة ومرجع سلطة محسوم وحالة الميثاق غير مفتوحة سلفا |
| سياسةُ الإعادة | إعادة الاعتماد على ميثاق مفتوح ترد بحالة نافذة |
| سلوكُ الفشل | ارتداد المعاملة كاملة — ولا مشروع بلا مركز تكلفة ولا موقع |
| التعويض | المعاملة ذرية فالارتداد هو التعويض ولا أثر جزئي يبقى |

**المستهلكونَ بالاسمِ وأثرُ كلٍّ منهم:**

| المستهلك | الأثرُ المقيس |
|---|---|
| ProjectOpeningService عند إدارة التشغيل | خدمة التشغيل تنشئ صف المشروع |
| سجل مراكز التكلفة عند الإدارة المالية | الإدارة المالية تستلم مركز تكلفة مربوطا بالمشروع |
| سجل المواقع عند إدارة الموقع | إدارة الموقع تستلم مواقع المشروع بموقع افتراضي |
| أثر التدقيق | أثر التدقيق يقيد الأثر الخماسي داخل المعاملة |

## `exec.authority.denied` — منع فعل قيادي لغياب سلطته

| البند | القيمة |
|---|---|
| المصدر | E1 مساحة الرئيس التنفيذي · `app/Services/Exec/ScopeEngine.php` |
| المحفِّز | رد حلال السلطة على فعل من مساحة القيادة أو مساحة عملي |
| الحمولةُ الدنيا | company_id · actor_user_id · action_key · verdict · rule_id · why |
| مفتاحُ منعِ التكرار | `exec:deny:{actor_id}:{action_key}:{doc_ref}` |
| الشروطُ المسبقة | محاولة فعل بلا قاعدة سلطة أو خارج النطاق أو بتفويض منته |
| سياسةُ الإعادة | التكرار يقيد بمرات ولا ينشئ صفوفا مكررة بالمفتاح نفسه |
| سلوكُ الفشل | فشل التقييد لا يفتح الباب — المنع يبقى قائما والتقييد يعاد |
| التعويض | لا تعويض — المنع ليس أثرا يعكس |

**المستهلكونَ بالاسمِ وأثرُ كلٍّ منهم:**

| المستهلك | الأثرُ المقيس |
|---|---|
| سجل المنع عند الحوكمة | سجل المنع يقيد المحاولة برمز ردها |
| فرز الحوكمة | الفرز يقرأ النمط والتكرار |
| تنبيه الحوكمة عند تكرار النمط | التنبيه يفتح عند بلوغ النمط ولا يفتح تحقيقا تلقائيا |
