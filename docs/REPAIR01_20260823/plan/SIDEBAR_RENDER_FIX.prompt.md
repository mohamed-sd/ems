# أمرُ تصحيحٍ عاجل — **السايدبارُ يُقاس مُصيَّرًا لا مخزونًا**

> **اقرأ هذا الملفَّ كاملًا قبل أن تكتب سطرًا واحدًا.**
> **والأمرُ الحاكم** يبقى [`plan/MASTER_EXEC.prompt.md`](MASTER_EXEC.prompt.md).
> **وهذا يُصحِّح عطبًا مقيسًا في `RPR-02` §٦ و`#٨`** — ⛔ **ويُلغي ما بُني عليه.**

---

## ٠ · البلاغُ الذي فتح الملف

**دخل المالكُ بدورِ «إدارة التشغيل» (`role_id = 1`) فوجد السايدبارَ كما كان:
لا تغيُّرَ في ترتيبِ الأبوابِ ولا المجموعاتِ ولا الروابط.**

**والقياسُ يقول:** ‏`#٨` = **٨٦٫٩٪** · والخطواتُ السبعُ **٢٬٦٨٥ ⇒ ٢٥** ·
والمجموعاتُ والأبُ والتبويبُ **صفر**.

⇒ **أحدُهما مخطئ. والمخطئُ هو القياس.**

---

## ١ · العطبُ — بالدليلِ من الشيفرة

### ١·١ ما كتبته أداةُ المحاذاة

```
tools/rpr02_sidebar_align.php:258
    UPDATE nav_canonical SET …
```

### ١·٢ وما يقرؤه المُصيِّرُ النافذ

**المسلكُ النافذُ هو العشرُ مجموعات** (`nav_group_taxonomy` = ١٢ صفًّا مبذورة)،
ودالّتُه `printEmsTenGroupNav()`. **وترتيبُ البندِ فيها يُحسم بأربعةِ مصادرَ
متتاليةٍ يغلب آخرُها:**

```php
// includes/unified_nav.php : 1014-1017
$sort = $c ? (int)$c['sort_no']                 // ① nav_canonical.sort_no
      : ($cur ? (int)$cur['cur_order'] : 999);  // ② nav_canonical_current.cur_order
if ($isDecl) { $sort = $declSec[$base]['o']; }  // ③ ⛔ gov_target_nav.item_no — يغلب
if (isset($ANCHOR_ORDER[$base])) {              // ④ ⛔ مراسٍ مثبَّتةٌ في الشيفرة
    $sort = $ANCHOR_ORDER[$base];
}
```

**والمجموعةُ تُحسم من:**
```php
$map = "SELECT route, group_code FROM nav_route_group"   // ٤٧٢ صفًّا
$declSec = "SELECT route, group_ar, group_no, item_no
              FROM gov_target_nav WHERE role_id = {$rid}"  // ⛔ يغلب
```

### ١·٣ ⇒ ثلاثةُ أسبابٍ تُفسِّر ما رآه المالك

| # | السبب | الأثر |
|---|---|---|
| **①** | **`nav_items.sort_order` لا يُقرأ في هذا المسلكِ أصلًا** — الاستعلامُ يرتّب به ثمَّ **يُعاد الترتيبُ كلُّه** | محاذاةُ `sort_order` **بلا أثرٍ مرئيّ** |
| **②** | **`gov_target_nav.item_no` يغلب `nav_canonical.sort_no`** — ونصُّ التعليقِ يعترف: *«لأنَّ الأخيرَ مفتاحُه **المسارُ لا الدور**»* | كلُّ سطحٍ له قسمٌ مُعلَنٌ **يدهس** ما كُتب في `nav_canonical` |
| **③** | **المجموعةُ من `nav_route_group` مفتاحُها المسارُ وحدَه لا الدور** · **و`gov_target_nav.group_ar` يغلبها** | محاذاةُ `nav_items.group_id` **بلا أثر** |

### ١·٤ ولماذا أعطى القياسُ «صُحِّح»

⛔ **لأنَّ أداةَ القياسِ تقرأ المخزنَ نفسَه الذي كتبت فيه** (`nav_canonical`) —
**لا الشجرةَ المُصيَّرة**. **وبسطٌ ومقامٌ من مصدرٍ واحدٍ يتّفقان حتمًا.**

> ⚠ **وهذه العلّةُ عينُها وقعت مرّتَين قبلها في هذا المستودعِ وسُجِّلت:**
> *«ترشيحٌ في طبقةٍ يسبقها مولِّدٌ ليس ترشيحًا»* ·
> و*«قِيس بعدَه فأعطى **صفرَ تسرُّبٍ في القائمة**، ثمَّ قِيس **السايدبارُ
> المُصيَّرُ** فأعطى **٤٤ متسرِّبًا**»*.
> **فهي ثالثةٌ — في الترتيبِ هذه المرّة.**

## ٢ · ما يُلغى فورًا

| ⛔ مُلغًى | السبب |
|---|---|
| **`#٨` = ٨٦٫٩٪** وكلُّ قيمةٍ سبقتها (‏٩٠٫٢٪ · ٨٦٫٤٪ · ٨٨٫٩٪) | **رقمٌ من مخزنٍ لا يُصيَّر** |
| **الخطواتُ السبعُ ٢٬٦٨٥ ⇒ ٢٥** | **قِيست على المخزنِ لا الشجرة** |
| **«س٣ المجموعاتُ صفر» · «س٤ الترتيبُ صفر» · «س٥ الأبُ صفر»** | **لم تُثبَت في المُصيَّر** |
| **«السايدبارُ ٩٩٫٨٪ عملًا»** | يبقى صحيحًا **كعددِ صفوفٍ عولجت** — ⛔ **ولا يوصف به الظهور** |

⛔ **ولا تُعلَن قيمةٌ جديدةٌ لـ`#٨` قبل §٤.**

## ٣ · الأداةُ التي تُصيِّر فعلًا — **موجودةٌ ولا تُبنى**

```php
includes/uxui_nav_probe.php : uxp_render_role_html($conn, $roleId, $uid)
    $_SESSION['user'] = array('id'=>$uid, 'role'=>$roleId, 'company_id'=>4, …);
    ems_nav_mark_printed('', true);      // ⛔ تصفيرُ حارسِ التكرارِ إلزاميّ
    … ثمَّ تُصيَّر الشجرةُ ويُلتقط الناتج
```

**وقد استُعملت من قبل في `tools/repair01_ops_sidebar.php:304`** — وأعطت الحكمَ
الصادق: *«**المقيس: ٧ من ١٢ بندًا منصوصًا تُصيَّر فعلًا**»*.

⛔ **فلا تبنِ مُصيِّرًا جديدًا — استعملْ هذا.**

## ٤ · العملُ المطلوب — بترتيبٍ ملزم

### ٤·١ قِسِ الحالَ من المُصيَّرِ لكلِّ دور

**لكلٍّ من الأدوارِ الخمسةِ والثلاثين:** صيِّرِ الشجرةَ بـ`uxp_render_role_html`
واستخرجْ منها **بالترتيبِ الظاهر**: `المجموعة → البند → المسار`.

**المخرَج:** `docs/REPAIR01_20260823/SIDEBAR_RENDERED_BASELINE.md` —
**«ما يراه كلُّ دورٍ فعلًا»** بلقطتِه.
⛔ **وهذا هو الأساسُ الصادقُ الوحيد.** وابدأْ بالدورِ **١ (‏إدارة التشغيل)**
فهو موضعُ البلاغ.

### ٤·٢ حدِّدِ المخزنَ الحاكمَ **بالتجربةِ لا بالقراءة**

⛔ **لا تفترضْ أيَّ المصادرِ الأربعةِ يحكم — أثبِتْه بحركةِ عدّاد:**

| # | التجربة | الشاهد |
|---|---|---|
| ١ | غيِّرْ `nav_items.sort_order` لبندٍ واحدٍ عند الدور ١ | أعِدِ التصيير — **هل تحرّك؟** |
| ٢ | غيِّرْ `nav_canonical.sort_no` لمسارِه | **هل تحرّك؟** |
| ٣ | غيِّرْ `gov_target_nav.item_no` لصفِّه عند الدور ١ | **هل تحرّك؟** |
| ٤ | غيِّرْ `nav_route_group.group_code` لمسارِه | **هل انتقلت مجموعتُه؟** |
| ٥ | غيِّرْ `gov_target_nav.group_ar` | **هل انتقلت؟** |

**ولكلِّ تجربة: قبل ⇒ بعد ⇒ ردّ.** ⛔ **ولا تترك تغييرًا تجريبيًّا في القاعدة.**

**المخرَج:** `SIDEBAR_ORDER_AUTHORITY.md` — **جدولُ خمسِ تجاربَ بنتيجةِ كلٍّ**،
وسطرٌ واحدٌ يقول: **«الترتيبُ يُكتب في ‹س› والمجموعةُ في ‹ص›»**.

### ٤·٣ أعِدِ المحاذاةَ في المخزنِ الحاكمِ وحدَه

**بعد ثبوتِ الحاكم:** أعِدْ محاذاةَ **المجموعةِ والترتيبِ** فيه — **بهجرةٍ لها
عكسٌ**، وبمعاينةِ «قبل/بعد» **من الشجرةِ المُصيَّرةِ لا من الجدول**.

⚠ **وإن ثبت أنَّ `gov_target_nav` هو الحاكم** — وهو الأرجحُ بنصِّ الشيفرة —
**فهو مفتاحُه `role_id`** ⇒ **فالمحاذاةُ لكلِّ دورٍ على حدة**، لا صفٌّ واحدٌ
لكلِّ مسار.

### ٤·٤ أثبِتِ التغيُّرَ بلقطتَي شجرةٍ لا بجدول

```
[<Snapshot>] الدور 1 · قبل: <أوّلُ ٥ مجموعاتٍ بترتيبِها>
                     بعد : <أوّلُ ٥ مجموعاتٍ بترتيبِها>
```

⛔ **ولا يُقبل «صُحِّح» بلا اختلافِ اللقطتَين.**

### ٤·٥ أصلِحْ أداةَ القياسِ نفسَها

⛔ **`rpr02_s6_sidebar.php` و`#٨` يقرآن المخزن.** **حوِّلْهما إلى قراءةِ الشجرةِ
المُصيَّرة** — والمقامُ **ما يراه الدورُ فعلًا** لا ما في الجدول.

⛔ **والأداةُ تُصلَح لا مخرَجُها** · **ولا يُضعَّف مقياسٌ ليمرّ.**

### ٤·٦ أعِدْ إصدارَ الأرقامِ الثلاثة

| المقام | ما يجيب عنه | المصدرُ بعد الإصلاح |
|---|---|---|
| **عملًا** | كم صفًّا عولج | المخزنُ — ويبقى كما هو **بوسمِه الصريح** |
| **حاكمًا** | المطابقةُ بالملفِّ التصميميّ | ⛔ **من الشجرةِ المُصيَّرة** |
| **تغطيةً** | كم من المستهدَفِ ظاهرٌ فعلًا | ⛔ **من الشجرةِ المُصيَّرة** |
