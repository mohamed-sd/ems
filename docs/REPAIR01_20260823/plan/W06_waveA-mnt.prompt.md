### ٦-أ · رحلةُ الإثبات — شرطُ بوّابةٍ لا توصية

**رحلةُ التوقّف (§18)**

> معدّةٌ في موقع ← تعمل ← تتوقّف ← يُسجَّل التوقّفُ **مرّةً واحدة** ← يتأثّر التشغيل ← تتأثّر الجاهزية ← يُحدَّد المشغّلُ الموجود ← الصيانةُ تستلم ← المخاطرُ تقرأ المحفِّز ← الحوكمةُ تقرأ خرقَ الضابطِ إن وُجد ← البلاغاتُ تتابع إن كانت هناك تذكرة ← القيادةُ ترى تنبيهًا حرجًا ← الإصلاح ← شهادةُ العودة ← الأسطولُ يعيد الحالة ← التشغيلُ يعيد الجاهزية.

**تُغلَّف الرحلةُ ببوّابةٍ داخل `repair01_w6_gate.php`** تشترط عبورَها **كاملةً** و**أثرًا تجاريًّا مقيسًا عند كلِّ مستهلك** — لا صفَّ حدثٍ مُنشَأً (§46).

⛔ **لا تُقبل المرحلةُ ببناءِ أسطحِها إن لم تعبر رحلتُها — ولو كانت كلُّ بوّاباتِها الأخرى خضراء.**

### ٦-ب · الفحصُ السلبيّ — شرطُ إغلاقٍ لا زينة
اكسرْ بندًا عمدًا ← أعِدْ تشغيلَ البوّابة ← يجب أن تسقط ← أرجِعْه.
لم تسقط؟ البوّابةُ عمياءُ والمرحلةُ **غيرُ مُغلقة** مهما كان الرقمُ أخضر.
ارسُ على أسماءِ الأصنافِ والمقاماتِ لا على العبارات — نصُّ حالةِ الخطأِ يطابق العبارةَ فيُخضِرُّ كذبًا.
اكتبْ `tools/repair01_w6_negative.php` على نمطِ `tools/repair01_w0_negative.php`.
