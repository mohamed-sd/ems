# قالب جواب DEC-OPEN-15

انسخ هذا الملف باسم `DEC-OPEN-15.answer.md` في المجلد نفسه ثم املأه بفئاتك.

**سطر لكل فئة بخمسة حقول مفصولة بعلامة الأنبوب:**

```
الفئة | الأعلام | سياسة المنتهي | ترتيب الصرف | السبب
```

- **الفئة** كما تكتبها في `proc_item.category` حرفا بحرف
- **الأعلام** واحد أو أكثر من `lot` و `serial` و `expiry` مفصولة بفاصلة
- **سياسة المنتهي** `BLOCK` منع كامل أو `WARN_OVERRIDE` تنبيه بتجاوز باعتماد — تلزم مع `expiry` وحدها
- **ترتيب الصرف** `FEFO` الأقدم صلاحية أولا أو `FIFO` الأقدم دخولا أولا أو `FREE` باختيار أمين المخزن — تلزم مع `expiry` وحدها
- **السبب** جملة تشرح لماذا تحمل هذه الفئة هذه الأعلام

## أمثلة توضيحية لا قرارات

```
زيوت وشحوم | lot | | | الدفعة المعيبة تسحب من كل المواقع دفعة واحدة
فلاتر | lot | | | العيب يظهر في دفعة كاملة لا في قطعة
محركات ومولدات | serial | | | لكل قطعة ضمان وسجل اصلاح وعهدة شخصية
اجهزة قياس | serial | | | المعايرة لكل جهاز على حدة
بطاريات | lot,expiry | BLOCK | FEFO | تنتهي صلاحيتها وتصرف الاقدم اولا
كيماويات | lot,expiry | BLOCK | FEFO | خطر السلامة يمنع صرف المنتهي
مواد اطفاء | expiry | WARN_OVERRIDE | FEFO | ينبه ويسمح بتجاوز باعتماد مسؤول السلامة
```

⛔ **الامثلة اعلاه ليست جوابا** — احذفها واكتب فئاتك انت.
