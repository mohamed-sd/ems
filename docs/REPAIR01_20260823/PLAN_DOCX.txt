1. القيادة التنفيذية العليا — Target القيادة.

3. ملفات الموجات A–E — المتطلبات التفصيلية لكل نطاق.
4. السجلات المؤسسية والقرارات — مصدر القرارات والمتطلبات والحقول والأحداث.
5. المصالحة مع النظام الحالي — AS-IS.
6. المراجعة الثانية — Independent Challenge.
7. مراجعة القيادة — مصالحة القيادة المستهدفة مع المبني.
