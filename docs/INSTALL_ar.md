# دليلُ تنصيب EMS

> **الخلاصة في سطرين:** التنصيبُ الأوّل بالمُثبِّت، وتغييرُ المخطَّط بعده
> بالمُشغِّل. المُثبِّتُ يبني قاعدةً من الصفر، والمُشغِّلُ يعدّل قاعدةً فيها
> بياناتُ عملاء. لا يُغني أحدُهما عن الآخر.

## ١. ما الذي يُنصَّب

| المصنوع | المحتوى |
|---|---|
| `database/schema/schema.sql` | 315 جدولًا + 5 مناظير — بنيةٌ بلا بيانات |
| `database/schema/seed_reference.sql` | 2337 صفًّا مرجعيًّا في 13 جدولًا |

**① عالمية** — بنيةٌ متنكّرةٌ في هيئة بيانات. بدونها لا تنقُّلَ ولا صلاحيات:

| `admin_companies` · `employees` · `users` | بياناتُ مستأجِرٍ — يُنشئها المُثبِّتُ من مدخلاتك |

## ٢. التنصيب عبر سطر الأوامر

المسارُ الأساسي. أنشئ ملفَّ إعدادٍ (JSON أوثقُ من الأعلام حين تحوي القيمُ عربيّة —
بعضُ الصدفات تُفسد ترميزَ `argv`):

```json
{
  "db_host": "localhost",
  "db_name": "ems_production",
  "db_user": "root",
  "db_pass": "",
  "db_create": true,
  "company_name": "شركتي",
  "company_email": "info@example.com",
  "company_currency": "SDG",
  "company_timezone": "Africa/Khartoum",
  "admin_name": "الاسم الكامل",
  "admin_username": "admin",
  "admin_email": "admin@example.com",
  "admin_password": "كلمة-مرور-قوية"
}
```

افحص أوّلًا — لا يكتب شيئًا:

```bash
php database/install.php --check --config=install.json
```

ثمّ ثبّت:

```bash
php database/install.php --config=install.json
```

`--yes` يتخطّى سؤالَ التأكيد (للأتمتة). واحذف ملفَّ الإعداد بعد التنصيب — فيه
كلمتا مرور.

## ٣. التنصيب عبر المتصفّح

لأن كثيرًا من الاستضافات المشتركة لا تمنح SSH.

أنشئ ملفَّ الرمز على الخادم:

```bash
php -r "echo bin2hex(random_bytes(16));" > install/install.token
```

ثمّ افتح `https://your-domain/install/` وأدخل محتواه مع بقيّة البيانات.

**بعد نجاح التنصيب: احذف مجلَّد `install/` بالكامل.**

### الحرّاسُ الثلاثة

| الحارس | السلوك |
|---|---|
| `.installed` موجودٌ في الجذر | رفضٌ قاطع — النظامُ مثبَّتٌ سلفًا |
| القاعدةُ غيرُ فارغة | رفضٌ في الفحص القبلي |
| `install/install.token` مفقودٌ أو غيرُ مطابق | رفضٌ قاطع |

الرمزُ ملفٌّ لا مفتاحٌ في `.env` لأنّ التنصيبَ يسبق وجودَ `.env`؛ فالشرطُ الوحيدُ
القابلُ للتحقّق قبله هو **إثباتُ الوصول إلى نظام الملفّات** — وهو بالضبط الصلاحيةُ
التي يجب أن يملكها من يحقُّ له التنصيب.

## ٤. لماذا يشترط المُثبِّتُ قاعدةً فارغة

MySQL لا يتراجع عن DDL داخل معاملة، فلا سبيلَ لتنصيبٍ ذرّيٍّ حقيقي. البديلُ
الأمين: نرفض العملَ ما لم تكن القاعدةُ خالية — فالفشلُ في منتصف الطريق لا يُتلف
شيئًا: تُسقَط القاعدةُ ويُعاد التنصيب. مُثبِّتٌ يعمل فوق قاعدةٍ عامرة أداةُ
إتلافٍ لا أداةُ تنصيب.

## ٥. لماذا الثلاثيّة

`login.php` يرفض أيَّ حسابٍ بلا موظّفٍ مُسنَد (عدا المدير الأعلى `-1`). فمُثبِّتٌ
يُنشئ صفَّ `users` وحده يُنتج نظامًا **لا يمكن الدخولُ إليه** — عطبٌ يظهر متأخّرًا
عند أوّل محاولةِ دخول. لذلك يُنشئ المُثبِّتُ ثلاثةَ صفوفٍ مترابطة، والحسابُ
يأخذ الدور `1` (إدارة التشغيل).

## ٦. بعد التنصيب: تغييرُ المخطَّط

المُثبِّتُ للتنصيب الأوّل فقط. أيُّ تغييرٍ لاحقٍ على قاعدةٍ فيها بياناتٌ حيّة
يمرّ بالمُشغِّل:

```bash
# ① ملفٌّ جديد: database/migrations/YYYY_MM_DD_slug.sql
php database/migrate.php up

# ② حدّث مصنوعات المُثبِّت — وإلّا صار متخلّفًا عن قاعدتك
php database/migrate.php dump-schema

# ③ التزم الاثنين معًا
```

**الخطوةُ ② ليست اختياريّة.** نسيانُها هو العلّةُ التي تقتل كلَّ مقاربةِ
«مُثبِّتٍ فقط»: تُضيف عمودًا وتنسى إعادةَ التوليد، فيصير مُثبِّتُك يُنتج قاعدةً
مختلفةً عن قاعدتك — بصمتٍ، حتى يومِ النشر.

### حارسُ الانحراف

يجعل النسيانَ صاخبًا. يقارن قاعدتين كائنًا وعمودًا وفهرسًا ومفتاحًا:

```bash
php tools/schema_drift.php --expected=قاعدة_التطوير --actual=قاعدة_مثبتة_حديثا
```

صفرُ فروقٍ = المصنوعاتُ مواكبة. رمزُ خروجٍ غيرُ صفريٍّ عند أوّل فرق.

## ٧. أين ذهبت الترحيلاتُ الـ241

إلى `database/_history/` — باقيةً في git، خارجَ مسارِ مسحِ المُشغِّل. أثرُها كلُّه
داخلٌ في `schema.sql`، وصفوفُها باقيةٌ في `schema_migrations` يعرضها `status`
مجموعةً في سطر `[archived]`.

لم تُحذف لأنّها الجوابُ الوحيدُ على «**لماذا** صار هذا العمودُ كذا؟». لقطةُ
المخطَّط تحفظ *ما هو كائن*، والترحيلاتُ تحفظ *كيف صار*.

## ٨. استكشافُ الأخطاء

| العَرَض | السبب |
|---|---|
| `بصمة schema.sql غيرُ مطابقة` | حُرِّر الملفُّ بيدٍ بعد التوليد — أعِد `dump-schema` |
| `القاعدة تحتوي N كائنًا` | أسقِط القاعدةَ أو اختر اسمًا جديدًا |
| `MANIFEST.json مفقود` | شغّل `php database/migrate.php dump-schema` |
| فشلٌ في منتصف التنصيب | أسقِط القاعدةَ وأعِد — لا تُكمِل فوق نصفِ بناء |
| الدخولُ يُرفض بعد التنصيب | تحقّق أنّ `users.employee_id` غيرُ صفري |
