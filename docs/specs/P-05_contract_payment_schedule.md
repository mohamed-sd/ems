## ① بطاقةُ الجرد

| الحقل | المقيس |
|---|---|
| `contract_payment_schedule` | **غيرُ موجود** — ولا جدولَ يقوم مقامَه |
| ما يعرفه النظامُ اليوم | **ما قُبض** (`contract_advances` · M-01 · 0 صفوفٍ حيّة) و**ما فُوتر** (`claims` + `fin_receivables`) |
| **ما لا يعرفه** | **«دفعةٌ مستحقةٌ يومَ كذا بمبلغِ كذا»** — فلا توقُّعَ ولا «متأخر»، **والتأخرُ يُكتشف بالمصادفة** |
| شروطُ السداد في الرأس | `contracts.payment_time` **VARCHAR(50) نصٌّ حرّ** · و`payment_date` **تاريخٌ واحدٌ للعقد كلِّه** · و`retention_pct` · `advance_recovery_pct` |
| `contract_advances` | **بلا نوع**: `id · amount · currency · received_date · doc_ref · state('recorded','cancelled')` |
| **ما يعنيه ذلك** | المقدمُ المستهلَك ورسومُ التعبئة ورسومُ الحجز غيرُ المستردة ودفعةُ المعلَم **تسكن صفًّا واحدَ الشكل** — و PLAN-03 §6: «**الخلطُ بينها يقلب التزامًا إلى إيرادٍ أو العكس**» |
| **الخللُ (من الستة)** | ③ بنيةٌ لا تحمل المفهوم: **الاستحقاقُ غيرُ ممثَّل**، و**نوعُ المقدم غيرُ ممثَّل** |
| **المسار** | ② بناءٌ جديدٌ فوق `P-03` — و`contract_advances` **تبقى القابضَ الوحيد للالتزام** فلا يُفتح مصدرٌ ثانٍ للرقم |

## ② المصير — ما بُني

### الهجرة `2026_09_28_p05_contract_payment_schedule.sql`
جدولٌ واحدٌ يحمل **الأنماط الثمانية** و**أنواع المقدم الأربعة** و**حقولَ السطر السبعة** و**الإصدارات**:

| المجموعة | المحتوى |
|---|---|
| **الأنماطُ الثمانية** (`pattern`) | دفعةٌ واحدة · مقدمٌ ثم تسوياتٌ شهرية · مقدمٌ جزئي · مقدمٌ على دفعات · دفعاتٌ عند معالمَ · مستخلصٌ شهري · دفعةٌ ختامية · ردُّ محتجز الضمان |
| **نوعُ الدفعة** (`payment_kind`) | مقدَّم · تسويةٌ شهرية · معلَم · ختامية · ردُّ محتجز · دفعةٌ واحدة |
| **أنواعُ المقدم الأربعة** (`advance_type`) | مستهلَك · تعبئة · حجزٌ غيرُ مسترد · معلَمٌ مكتمل |
| المعالجة | `treatment` (`liability`/`revenue`) + `treatment_basis` نصُّ العقد |
| النسبةُ أو المبلغ | `amount_basis` · `percent_value` · `amount_expected` · `currency` |
| الاستحقاق | `due_date` **أو** `due_condition` |
| المستلمُ والمتبقي | `received_amount` + `remaining_amount` **عمودٌ مولَّد** |
| الحالُ الخمس | `not_due` · `due` · `partial` · `completed` · `overdue` |
| مرجعُ التحصيل | `collection_ref` + `advance_id` (وصلٌ لدفتر السلف) |
| الإصدارات | `version` · `effective_from/to` · `amendment_id` |

**والقيدُ الحاكمُ بنيويٌّ** (`ck_cps_treatment`): المستهلَكُ ⇒ `liability` **حتمًا** · والحجزُ والمعلَمُ ⇒ `revenue` **حتمًا** · والتعبئةُ ⇒ **أيُّهما نصَّ العقدُ عليه، و`treatment_basis` إلزاميٌّ لها**. و`ck_cps_advance_link`: **لا يُوصَل بدفتر السلف إلا الالتزام** — فلا يُستقطع إيرادٌ من مستخلص.

> **ولا يُفرَض «Σ الخطة = قيمةُ العقد»** — والامتناعُ **قرارٌ مقيسٌ لا سهو**: المقدمُ يُستهلك من المستخلصات فلا يُجمع معها، وقيدٌ كهذا **يكذب** على كل عقدٍ فيه مقدَّم. والقيدُ الصادقُ صفٌّ صفًّا: المقبوضُ ≤ المتوقَّع، والنسبةُ في (0,100].

### `ContractPaymentScheduleService` — أربعُ قواعد
| # | القاعدة | الأثر |
|---|---|---|
| ① | **أنواعُ المقدم لا تُخلط** | المعالجةُ **محكومةٌ بالنوع** ⇒ 422 عند القلب · والتعبئةُ **بلا نصٍّ** ⇒ 422 |
| ② | **ودفترُ السلف للالتزام وحدَه** | الالتزامُ يُقبض بـ`advance_record` (M-01) **نفسِها** — والإيرادُ **لا يدخلها بتاتًا** |
| ③ | **والزائدُ يُعلَن ولا يُبتلع** | 409 بالفائض · و«**رصيدٌ دائنٌ للعميل لا إيراد**» وبيتُه `P-07` |
| ④ | **والملحقُ يفتح نسخةً** | القديمةُ تُختم بـ`effective_to` وتبقى · **والمقبوضُ يُرحَّل** لأن القبضَ واقعةٌ لا تُلغيها نسخة |

**والتوليدُ من الجدول لا من التخمين:** شهرٌ كميتُه صفر (**توقف**) ⇒ **لا سطرَ دفعٍ له**؛ ومهلةُ السداد تُزاح عن نهاية الشهر؛ وردُّ المحتجز **بشرطٍ لا بتاريخ**. وعقدٌ **بلا جدولٍ شهريٍّ نافذ** ⇒ **422**، وعقدٌ بعملتين ⇒ **422**.
