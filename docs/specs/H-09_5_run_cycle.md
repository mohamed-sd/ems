# H-09-⑤ — المسيّرُ والكشف (بطاقةُ مواصفة · **إغلاقُ H-09**)

> **المصدر الحاكم:** ENT-01 §5 (جدولُ انتقالات الدورة · الكشفُ الفردي) · §6 (المعالجةُ المحاسبية بجهة التحمّل · **الأثرُ الواحد**) · §7 (الشاشاتُ الثلاث) · **PLAN-01 §6.1-⑤**.
> **المانع:** H-09-④ — **مغلقة**. **الحالة:** مكتوبة 2026-07-30.

---

## ① المصير — لا جداولَ جديدة

كلُّ ما تحتاجه الشريحةُ مبنيٌّ في ①→④: الرأسُ بحالاته السبع · الأسطرُ بلقطاتها · الموانعُ بنوعيها · الخصومُ بمراجعها. والناقصُ **الآلةُ والحراسُ والكشف** — فلا هجرة.

### `PayrollStateMachine`
قائمةُ سماحٍ من جدول §5 حرفيًّا (نمطُ H-02):

| الانتقال | الحارسُ المنفَّذ |
|---|---|
| Open → Calculated | (يتولّاه `bindSnapshots`) |
| Calculated → Blocked | (تلقائيٌّ من الموانع) · Blocked → Calculated بعد الإصلاح |
| Calculated → **Review** | **صفرُ صفٍّ أحمر** · اكتمالُ الأسطر · فترةٌ غيرُ مقفلة |
| Review → **Approved** | **صفرُ صفٍّ أحمر** · **لا اعتمادَ للذات (403)** · **حدثُ FES** |
| Approved → **Paid** | **مرجعُ الصرف إلزامي (422)** |
| Paid → **Closed** | **لا سطرَ معلَّقًا** — والمقفلةُ **نهائيةٌ بلا رجوع** |

### تعريفُ «الصفِّ الأحمر» — من النص لا من الرأي
§7 يقول: «**صفٌّ بلا لقطةٍ صالحةٍ يظهر أحمرَ ولا يُعتمد**». فـ`redRows()` ترصد ثلاثةً **كلًّا باسمه**:

| اللون | المعنى |
|---|---|
| `pending` | سطرٌ لم يكتمل احتسابُه (`pending_slice`) |
| `blocked` | مانعٌ مفتوحٌ من نوع `blocked` — «لا احتسابَ ناقصٌ صامت» (والمستبعَدُ **ليس** منها) |
| `tampered` | لقطةٌ لا تطابق بصمتَها أو سطرٌ بلا لقطة — **تلاعبٌ مكشوف** |

ولا يُعتمد شيءٌ منها **أبدًا**، ولو أذن به صاحبُ أعلى سقف.

### «الأثرُ الواحد» (§6)
حدثُ `payroll.settlement.approved` **واحدٌ لكل (شخص × فترة)** بمفتاح عطالةٍ `payroll_settlement:‹person›:‹YYYY-MM›` — فإعادةُ الاعتماد **تعيد المرجعَ ولا تكرر** (مثبَتٌ: 3 أحداثٍ تبقى 3 بعد دورةِ رجوعٍ واعتمادٍ ثانٍ).

### الكشفُ والسجل (§7)
`payslip()` **بطبقاته** (الأجرُ والبدلات · الإنتاج · الحوافزُ بأساسها · الإضافي · خصمُ الغياب · **الخصوماتُ بمراجعها**) وكلُّ سطرٍ بمصدره ولقطته · و`register()` صفٌّ لكل شخصٍ **بتذييلٍ ثابتٍ بالمجاميع**، **والأحمرُ يظهر أحمرَ فعلًا** في الشاشة.

## ② القبول — معيارُ PLAN-01 §6.1-⑤ حرفيًّا
> «فترةٌ كاملةٌ بلا تدخلٍ يدويٍّ و**صفرُ صفٍّ أحمرَ معتمد**»

`tests/payroll_run_cycle_test.php` — **32/0**:
- **الدورةُ الكاملةُ بلا تدخل**: فتحٌ ← لقطاتٌ ← مسارٌ زمني ← مقاصّةٌ ← مراجعةٌ ← اعتمادٌ ← صرفٌ ← إقفال.
- **الألوانُ الثلاثةُ تُختبر كلٌّ على حدة** وتُرفض المراجعةُ في كلٍّ منها، ثم تمرّ بعد إصلاحها.
- «لا اعتمادَ للذات» **403** · «الصرفُ بمرجعه» **422** بلا مرجع · القفزُ خارج الجدول **422 بالمسموح مسمًّى**.
- الكشفُ: 2000 − 400 = **1600** بطبقاته · والسجلُّ: مجموعُ صافٍ **6100** وصفرُ أحمر.
- المقفلةُ **لا تُفتح** وإعادةُ الربط عليها **423**.
