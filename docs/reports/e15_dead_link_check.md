# E-15 · سجلُّ فحص الرابط الميت — `Maintenance/breakdowns.php` (module 42) — 2026-08-01

> **المصدر:** UX-07 §3 · §8.1 — «تنظيفُ الرابط الميت 71 بسجل فحصٍ يثبت صفره».
> (71 ترقيمُ الوثيقة · وفي القاعدة هو `modules.id = 42` «البلاغات (غير مفعّلة)».)

## القياس (2026-08-01)

| الفحص | النتيجة |
|---|---|
| صفوفُ `nav_items` تشير إليه | **صفر** — لا رابطَ في أي سايدبار |
| صفوفُ `role_permissions` عليه | 2 (موروثةٌ خاملة — لا تفتح شيئًا لأن الشاشةَ محوِّلة) |
| محتوى الملف | **محوِّلٌ خالص** إلى `Tickets/tickets_list.php` منذ استيعاب S12 — لا منطقَ فيه |
| الجدولُ `mnt_breakdown` | باقٍ للقراءة (تشير إليه `mnt_order.breakdown_id`) — **لا يُمسّ** |

## ما فُعل (لا حذف — عقد العمل ④)

1. أُضيف **عدّادُ hits** إلى التحويل عبر `nav_redirects`
   (`old_route='Maintenance/breakdowns.php'` → `Tickets/tickets_list.php`) —
   كلُّ نقرةٍ على الميت تُعَدّ وتُختم بوقتها.
2. صفُّ `modules` 42 وصفّا الصلاحية **بقيا** — الحذفُ النهائيُّ **قرارُ مالكٍ**
   بعد أن يثبت العدّادُ صفرَه مدةً كافية (SPEC-00 §3-②: «حتى يصفر»).

## معيارُ الإقفال النهائي (بيد المالك)
`SELECT hits, last_hit_at FROM nav_redirects WHERE old_route='Maintenance/breakdowns.php'`
— صفرُ hits بعد شهرٍ = أمانُ الحذف من `modules` إن أراده.
