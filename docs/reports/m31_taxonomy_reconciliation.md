# M-31 · تقريرُ مطابقة توحيد تصنيفَي الأعطال والبلاغات — 2026-08-01

> **المصدر:** UX-04 §3 · UX-07 §8.1 — «جدولان متوازيان يفسدان تقريرَ التكرار».

## القرار
- **القانوني:** `failure_codes` (402 صفًّا · 4 طبقات · 83 فئةً رئيسيةً مميزة) —
  الأغنى والموصولُ فعلًا بأوامر الصيانة (`mnt_order.failure_code_id`).
- **الموصول:** `ticket_categories` (8 صفوف) أُضيف إليه `failure_main_code`
  مؤشرًا إلى الفئة الرئيسية — **ولم يُحذف أيُّ جدولٍ ولا صف** (عقد العمل ④).
- **الواجهة:** `unified_fault_taxonomy` (VIEW · 83 فئة) — يقرأ منها تقريرُ
  التكرار (M-35 · الشاشة 197).

## التعبئةُ الرجعية (8 تصنيفات بلاغات)

| تصنيف البلاغ | الوصلة | الأساس |
|---|---|---|
| المحرك | MEC أعطال الميكانيكا | دلالي |
| هيدروليك | HYD | دلالي |
| كهرباء | ELE | دلالي |
| حدادة ولحام | BDY الهيكل والقبين | دلالي |
| مكيّف | COL التبريد والتكييف | دلالي |
| بنشر وإطارات | TRK الإطارات والجنزير | دلالي |
| غيار زيت | PMP وقائية مخططة | دلالي |
| **غير ذلك** | **NULL — موروثٌ بلا مقابلٍ يُعلَن** | لا يُخترع له كود |

- مطابقةُ الاسم الآلية في الهجرة أصابت **صفرًا** (الأسماءُ مختلفةُ الصياغة) —
  فالخريطةُ أعلاه **قرارٌ دلاليٌّ مدوَّنٌ** طُبّق ببيانٍ لكل صف.
- «غير ذلك» بقي بلا وصلةٍ **عمدًا**: تقريرُ M-35 يعرضه سطرَ
  «موروثٌ يُعلَن» — واختراعُ كودٍ له تلفيق.

## الأثر
- تقريرُ الأعطال (197) يجمع أوامرَ الصيانة والبلاغاتِ على محورٍ واحدٍ
  (`main_category_code`) — وكان مستحيلًا قبل الوصلة.
- صفرُ حذفٍ · صفرُ إعادة تسمية · والشاشتان القائمتان لإدارة التصنيفين
  باقيتان (الإخفاءُ/الدمجُ الشاشيُّ قرارُ واجهةٍ لاحقٌ لا بنية).
