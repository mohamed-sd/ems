# القسم الثاني 🔍 · تاسكٌ تُجرَّب بالاستعلام لا بالشاشة

هذه بنيةٌ لا سلوك — تُرى بأمرٍ واحد:

```bash
php -r "require 'config.php'; foreach(['contract_obligations','contract_penalty_rules','contract_penalty_assessments'] as \$t){ \$r=\$conn->query(\"SHOW TABLES LIKE '\$t'\"); echo \$t.': '.(\$r->num_rows?'موجود':'مفقود').PHP_EOL; }"
```

| التاسك | كيف تتأكد |
|---|---|
| البنودُ التسعة | `SHOW COLUMNS FROM contract_obligations LIKE 'obligation_type'` — ترى التسعةَ في الـENUM |
| قاعدةُ «ما لم يُنص عليه = الشركة» | نفسُ الأمر على `obligor` — ترى `DEFAULT 'company'` |
| تسعةُ أعمدةِ الإسناد | `SHOW COLUMNS FROM unit_time_log` |
| المحورُ الثاني | `SHOW COLUMNS FROM contract_hour_policies LIKE 'obligation_type'` |
| نسبتا الاستقطاع | `SHOW COLUMNS FROM contracts LIKE '%_pct'` |
| سريانُ الملحق ونوعُه | `SHOW COLUMNS FROM contract_amendments LIKE 'amend_type'` — ترى «تغيير التزامات» |
| **نموذجُ النقلة** | `grep -n "نقلة" app/Services/EffectFanout.php` — ترى `'نقلة' => 'trip'` |
| علمُ الرجوع | السطر 104 في `.env` |

✅ الحفظُ يمرّ مسودةً · **والاعتمادُ يُرفض برسالةٍ صريحة**

### تجربة ٤ — ⭐ الفرقُ المالي (**أهمُّ تجربة**)

# ما لم يُبنَ — لا تجرّبه

❌ **ردُّ الضمان المحتجز** — يُحتجز ولا يوجد زرُّ ردٍّ بعد
❌ **شارةُ الانكسار على ملف العقد** — على شاشة الجزاءات فقط
❌ **قائمةُ المسؤول في شاشة الدوام** — عامةٌ (اللوحةُ هي من تطبّق بنودَ العقد)
❌ **تعليقُ العقد · تعديلُ الأسعار · تبويباتُ ملف العقد · حاوياتُ الموردين** — خارجَ النطاق بقرارٍ مسبق
