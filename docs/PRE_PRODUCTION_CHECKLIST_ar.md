# قائمة ما قبل الإنتاج — EMS Pre-Production Checklist

**المرجع:** EQUIP-ARC-R02 (المرحلة 0) · أُنشئت 2026-07-07 ضمن تنفيذ ADR-04
**القاعدة:** لا إطلاق قبل اكتمال كل بند وتأشيره بالتاريخ والمنفِّذ.

> البنود مرتَّبة بالاعتماد المتبادل — نفِّذها بالترتيب.

## أ — الأسرار والوصول (ADR-04)

- [ ] **تدوير كلمة مرور قاعدة الإنتاج** من hPanel → Databases → Change Password
      (الكلمة الحالية مكشوفة في تاريخ git ولا قيمة لأي بند أمني قبل هذا).
- [ ] **إنشاء `.env` على سيرفر الإنتاج** من القالب `.env.example` بالقيم الجديدة —
      الكلمة الجديدة لا تدخل الكود ولا المستودع ولا المحادثات أبدًا.
- [ ] **مفاتيح cron إنتاجية** جديدة عشوائية في `.env` الإنتاج
      (`php -r "echo bin2hex(random_bytes(20));"`) وتحديث أي جدولة تستخدم مسار الويب.
- [ ] **مستخدم قاعدة بيانات مخصص للتطبيق** بصلاحيات DML فقط
      (SELECT/INSERT/UPDATE/DELETE — بلا ALTER/CREATE/DROP) يستخدمه التطبيق،
      ومستخدم منفصل للمُشغِّل بصلاحيات DDL — إن أتاحت الاستضافة ذلك.
- [ ] **التحقق أن `.env` محجوب عبر الويب على الإنتاج**:
      `curl -s -o /dev/null -w "%{http_code}" https://<domain>/.env` → يجب 403/404.

## ب — تنظيف المستودع (تاريخ git)

- [ ] **محو الأسرار والنسخ من كل تاريخ git** بأداة BFG أو `git filter-repo`:
      كلمة المرور القديمة + `database/equipation_manage (29).sql` + `database/backups/` + `logs/*.log`
      ثم `push --force` وإبلاغ كل من يسحب من المستودع (يعيد الاستنساخ).
      *(مؤجَّل بقرار 2026-07-07 لأن البيانات الحالية تجريبية — ينفَّذ هنا إلزاميًا.)*
- [ ] التحقق بعد المحو: `git log --all -S "Aaammm" --oneline` → صفر نتائج.

## ج — قاعدة البيانات (ADR-03)

- [ ] **حذف البيانات التجريبية** وتجهيز بيانات التأسيس الإنتاجية.
- [ ] **خطّ أساس رسمي من قاعدة الإنتاج**: `php database/migrate.php baseline`
      على السيرفر — يصبح المرجع المعتمد بدل اللقطة المحلية.
- [ ] `php database/migrate.php status` على الإنتاج → صفر pending، صفر failed.
- [ ] **أرشفة جداول `_bak_*`/legacy خارج القاعدة الحية** (بند المرحلة 0 المتبقي —
      منها `drivers_legacy_backup` و`_bak_unify_*`).

## د — التجميد والمراقبة

- [ ] مراجعة `logs/security.log`: أسبوع نظيف بلا `RUNTIME_DDL_EXECUTED`
      → قلب `EMS_DDL_FREEZE = true` في config.php.
- [ ] مراجعة لوحة `admin/csrf-monitor` → إكمال الحجب المتدرج لكل المسارات عبر
      `CSRF_ENFORCE_PATHS` ثم قلب `EMS_CSRF_ENFORCE=true` (الدليل: docs/CSRF_ROLLOUT_GUIDE_ar.md).
- [ ] تشديد fallback الاتصال: بعد استقرار `.env` في كل البيئات، تحويل غيابه من
      «تحذير + قيم محلية» إلى **فشل صريح برسالة واضحة** (fail-fast) — سطر واحد في config.php.
