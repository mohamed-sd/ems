## 1. الملخّص التنفيذي المعماري

النظام Monolith إجرائي متمركز حول الصفحة (الملف=المسار، بلا Router) بقشرة OOP حديثة (`app/` PSR-4)، **لكن طبقة وصول البيانات صارت إلزاميةً موحَّدة**: كل شاشةٍ وظيفية — من إدخال ساعات الدوام إلى كونسول المزوّد — تصل القاعدة عبر بوابة `TenantDb` التي تحقن قيد الشركة وتفرض دورة الحياة (حذف ناعم، ملكية، تعليل) وترفض ما خرج عن السجل.

**الرحلة بالأرقام:** من ~1135 نداءً خامًّا مبعثرًا (v1) إلى **117 نداءً متبقيًا كلها مصنّفة** (§9): قناتا محرّكين موثّقتان، وعائلة مصادقةٍ بنيوية، واستثناءات كونسولٍ معدودة، وسطح `api/` المؤجَّل بقرار المالك. **صفر نداء خامٍّ غير موثَّق في أي شاشةٍ وظيفية.**

**الخط الأحمر صامد منذ ولادته:** دفتر الأحداث المالية = 10 صفوف، مؤشر مستهلك المالية = 141 — لم يتحركا عبر تسع دفعات هجرة، وخطّاف النشر الحي (`EMS_EVENT_HOOKS=publish`) عبر معبر الاعتمادات هوجر بايت-حرفيًا.

## 2. النمط المعماري العام — الطبقات بعد الإغلاق

```
┌─ طبقة العرض: شاشات PHP (الملف=المسار) + insidebar/inheader + مكوّنات موحّدة (Excel/Modal/Forms/Topbar)
├─ طبقة الحراسة: الجلسة → حارس الأفعال (AJAX) → صمّام fail-closed (شاشات غير مسجَّلة) → CSRF مركزي
├─ طبقة الوصول (الإلزامية الجديدة):
│    ems_tenant_db()            ← بوابة المستأجر (تحقن company_id من الجلسة)
│    ems_tenant_db()->forAllTenants(reason)  ← قراءة السوبر العابرة المسجَّلة
│    ems_platform_db()          ← بوابة كونسول المزوّد (من جلسة super_admin)
│    القنوات المحكومة           ← ناقل الأحداث · محرّك الاعتمادات · محرّك الصيانة · ems_runtime_ddl
├─ طبقة البيانات: MySQL 8.4 · 148 جدولًا (123 بعمود company_id) · 3 views محسوبة · 50 ترحيلًا مفحوص checksum
└─ الحدود الخارجية: api/ (token — مؤجَّل) · cron (مفاتيح env fail-closed)
```

## 3. بوابة العزل `TenantDb` — العقد النهائي

**13 دالة عامة:** `select` · `selectOne` · `count` · `insert` · `update` · `softDelete` · `deleteRow` (صلب معلَّل) · `deleteChild` (ابن بمطابقة parent/fk حرفية، يشمل أبناءً بلا company_id عبر الأب المملوك) · `replaceChildren` · `runInTransaction` (معاملة مُدارة، الحراسة كاملة داخلها، أي رفض = rollback الكل) · `scopedQuery` (المركّب المعزول) · `forAllTenants` (عابرة مسجَّلة) · بوابة المنصّة عبر `fromSuperAdminSession`.

**سجل الجداول fail-closed — 6 تصنيفات (القياس الحي):**

| التصنيف | العدد | الدلالة | بوابة المستأجر |
|---|---|---|---|
| `T_TENANT` | 121 | بيانات شركةٍ بعمود company_id | حقنٌ صارم |
| `T_CHILD` | 5 | ابنٌ يُعزل عبر أبيه (منها الـviews المحسوبة v_worker_*) | EXISTS على الأب |
| `T_CATALOG` | 1 | كتالوج عام + ملكي | قراءة عامة/كتابة محوكمة |
| `T_GLOBAL` | 7 | مراجع النظام (roles/modules/failure_codes/…) | قراءة بلا تنطيق، كتابة سوبر/عابرة |
| `T_RESTRICTED` | 9 | بنية الناقل + جداول محرّك الاعتمادات + الترحيلات | **رفض تام — القناة هي المالك** |
| `T_PLATFORM` | 7 | طبقة المزوّد (شركات/اشتراكات/مديرون أعلون/tokens) | رفض للمستأجر، تنفتح للعابرة المنصّية |

**قواعد `scopedQuery` الحاكمة:** `scope` = كل جدولٍ مستأجرٍ مصدرَ صفوف (يُحقن `alias.company_id=?`؛ **يقبل LEFT-موصولًا** — للمستأجر شرط WHERE يكافئ INNER وللعابرة 1=1 فيبقى LEFT للسوبر)، `enrich` = LEFT حصرًا بلا حقن، `{TENANT_SCOPE}` مرةً واحدة بعد WHERE العلوية، لا نص `company_id` حرفيًا، SELECT فقط، لا UNION، كل جدولٍ مسجَّلٍ غير عام يجب إعلانه.

## 13. الأنماط والدروس المعمارية المكتسبة (خلاصة أ→ز)

1. **scope-على-LEFT** يطابق حرفيًا نمط «تنطيقٍ يدويٍّ في WHERE على جدولٍ LEFT» للمستأجر والسوبر معًا — مفتاح هجرة محركات التقارير.
2. **الاستعلام الفرعي المرتبط** بداخله INNER JOIN: يُقلب LEFT (شرط WHERE على عمود الجدول الأيمن يكافئه) فيمرّ فحص الإثراء؛ وإن كان مستقلًا يُفكّ لاستعلامين + دمج PHP بايت-مطابق.
3. **الأنواع الأصلية للمعاملات المُهيّأة** تكسر مقارنات `=== '1'` في الشاشات القديمة → مُعِيد صفوفٍ نصوصًا يحفظ NULL (سلوك mysqli حرفيًا). يُفحص كل ملفٍ فيه `===` على أعمدة رقمية.
4. **استعلام top-N داخلي منطوق** (recent-1000): يُفكّ لنداء معرّفاتٍ منطوقٍ مستقل + IN خارجي.
5. DISTINCT/`ORDER BY FIELD` على مرجعٍ عام = select ثم dedupe/usort مستقر في PHP (استقرار PHP 8 مضمون).
6. الكتابة المركّبة = `runInTransaction` واحدة (سجل + أبناء عبر select→deleteRow معلَّل→insert).
7. جداول محرّكٍ يملكها المحرّك = T_RESTRICTED + دوال قناةٍ للشاشات — لا استثناءات شاشةٍ متناثرة.
8. **گوتشا الترميز الحرجة:** لا تُعِد كتابة ملفٍ عربيٍّ بقراءة PowerShell الكاملة (`Get-Content -Raw` يقرأ ANSI بلا BOM فيُفسد UTF-8) — أدوات Edit الجراحية فقط، وخطّاف الترميز قبل الالتزام هو الشبكة الأخيرة.
9. علما الأصل `is_active` خانة اختيار (isset لا القيمة)، ومقبض البوابة يُرفع لأعلى ملفات الإجراءات متعددة الفروع.
